# VoiceCapture для Windows: анализ и план адаптации

Дата создания и обновления: 21 сентября 2026 года. Статус: **план утверждён, без live; после версии 0.1.1 пользователь потребовал переход на sherpa-onnx / NVIDIA Parakeet TDT v3**.

## Актуальное изменение архитектуры — версия 0.2.0

Этот раздел имеет приоритет над исходными требованиями Whisper/Vulkan ниже. Исторический анализ Mac и обоснование первой реализации сохранены, но Whisper больше не является локальным движком текущей Windows-поставки.

- Локальное распознавание: sherpa-onnx 1.13.8, NVIDIA Parakeet TDT 0.6B v3, ONNX INT8, CPU. NVIDIA GPU/CUDA не нужны; прежний Vulkan не переносится. Захват остаётся WASAPI/NAudio, обработка голоса — в памяти.
- Модель: 25 языков с русским/английским, автоматическое определение языка, пунктуация/регистр. Язык и словарь в настройках применяются только к OpenAI. Многоязычная модель не гарантирует точность каждого переключения языка.
- Экспорт сопровождающего sherpa-onnx: четыре файла, около 640 МиБ, закреплённая ревизия и SHA-256 каждого компонента. Установка всего пакета через временную папку; повреждённый пакет не активируется; проверка перед нативной загрузкой.
- Старые настройки мигрируют в памяти с уведомлением; модель/ускорение меняются на Parakeet/CPU, остальные параметры сохраняются, запись настроек только по «Сохранить». Старые модели не удаляются.
- Гибрид OpenAI + Parakeet сохраняет прежнюю гонку, один корректор и одну вставку. Esc прекращает ожидание немедленно; синхронный нативный блок завершается под семафором, поздний результат отбрасывается. Нельзя освобождать модель во время расчёта.
- Лимит записи пять минут сохранён; локальная обработка блоками до 25 с ограничивает память, ищет тихий стык после 20 с. Качество непрерывной речи на стыках требует проверки. Live не добавлен.
- На Windows 10/UHD 630 подтверждены CPU-инференс из Unicode-пути, отмена и повторное использование; 54 автотеста. Английский публичный WAV и русский синтетический материал прошли проверку контрольных слов; это не приёмка реального микрофона и не доказательство устранения первоначальной ошибки диктовки.
- Лицензии: sherpa-onnx Apache-2.0, ONNX Runtime MIT, NVIDIA Parakeet CC BY 4.0 с указанием INT8 ONNX-конвертации. [Инструкция и ограничения текущей версии](../voice-capture-win/README.md), [атрибуция](../voice-capture-win/THIRD_PARTY_NOTICES.md).

Далее — исходный план и результаты выпусков 0.1.x; положения о Whisper/GPU заменены указанным выше решением по прямому запросу пользователя.

Реализована первая сборка 0.1.0: [инструкция и фактические результаты проверки](../voice-capture-win/README.md), [решение](../voice-capture-win/VoiceCapture.slnx). Закреплены .NET 10, NAudio 2.2.1 и Whisper.net 1.8.1 CPU/Vulkan. Новейшая документация Whisper.net требует Windows 11, поэтому версия 1.9.1 не выбрана автоматически. На Windows 10 22H2 проверены запуск WPF, нативная библиотека и полное распознавание Base на CPU и с выбором Vulkan-runtime, отмена и повторный проход. Исправлен нативный сбой Unicode-пути. 26 автотестов проходят, Release-сборка без предупреждений. Самодостаточный архив подготовлен; реальные микрофон/OpenAI/вставка, AMD/NVIDIA и Windows 11 остаются ручной приёмкой. .NET 10 LTS подтверждён официальной матрицей; жизненный цикл Windows 10 ограничивает официальную поддержку Microsoft. Сайт OpenAI всё ещё возвращает 403, материалы SDK доступны через GitHub, живой API не проверен.

Дополнение 0.1.1 по запросу пользователя: поддержка Intel UHD, включая текущую UHD 630 (драйвер 30.0.100.9805). Добавлены определение адаптеров, Base для новых Intel UHD-only настроек, Auto на CPU, явный Vulkan и отображение backend. Старые модель/режим не перезаписываются; поведение Auto на UHD теперь консервативное CPU. 38 тестов проходят, опубликованная сборка запускается. На публичном фрагменте Base медианы трёх прогретых проходов: CPU 2,07 с, явный Vulkan 1,53 с; отмена и повторный проход успешны. Offload на GPU независимо не измерялся, все поколения UHD не испытаны. Подробности и ограничения — в актуальной инструкции выше.

## Зафиксированные требования и открытые решения

- Windows 10 и Windows 11; RAM от 16 ГБ; CPU от Intel Core i5-12400; обязательный микрофон. Предлагаемая архитектура поставки — x64.
- Исходная цель — AMD/NVIDIA, по формулировке пользователя не старше трёх лет с даты выхода. Дополнительным запросом включены Intel UHD Graphics, в том числе UHD 630 текущего ПК. Возраст карты не ограничивается программно; нужны совместимые драйвер/API и память. Для UHD предусмотрен облегчённый CPU-профиль и ручной Vulkan, без гарантии GPU-ускорения на всех поколениях.
- Стек **C# + WPF** принят; версия .NET и минимальная сборка Windows 10 уточняются по матрице совместимости. Совместимость приложения с Windows 10 не равна гарантии актуальной поддержки самой ОС её производителем.
- Прямой OpenAI API с личным ключом: **распознавание и коррекция текста**, приоритет скорости. Перевод исключён.
- Локальный Whisper обязателен в первом релизе. Гибрид OpenAI + Whisper входит в желаемый объём первого релиза. Groq не включаем: подтверждения его необходимости нет, облачную роль выполняет OpenAI.
- Русский, английский и смешанная речь; без перевода английских фрагментов в русский или наоборот.
- Нет истории текстов, хранения исходника/результата на диске, сохранения аудио и текстов в логах. Защита API-ключа сохраняется; шифрование отсутствующей истории не требуется.
- Личное использование. Приняты предложенные параметры: русский интерфейс, самодостаточный x64-архив, автозапуск по выбору и отсутствие автообновления.
- **Выбран A: без live.** Только индикатор записи во время речи; распознавание, коррекция и вставка после отпускания. Whisper и гибрид обязательны.

Разделы 2–4 описывают исходное Mac-приложение, в том числе его историю и перевод; эти функции не являются требованиями новой Windows-версии. Максимальная близость к Mac ограничена явными исключениями пользователя.

## 1. Вывод и границы анализа

Нужна новая Windows-оболочка с воспроизведением поведения Mac-приложения, а не механический перенос Swift-кода. Интерфейс, захват звука, хоткеи, вставка и перевод завязаны на Apple. Переносимы пользовательский сценарий, правила обработки и локальный движок Whisper при отдельной сборке для Windows.

**Выбранное направление:** C# + WPF + .NET 10; Windows-приложение в трее без собственного сервера. OpenAI и локальный Whisper — обязательные провайдеры распознавания; отдельный OpenAI-корректор обрабатывает финальный текст. Перевода, истории и live нет. Гибрид входит в первый релиз.

Первоначальный анализ охватил основные Swift-компоненты, документацию, зависимости, сборочные сценарии и Windows-возможности Whisper. Mac-приложение не запускалось, дефекты не воспроизводились на Mac. После утверждения создана Windows-реализация; результаты её проверки описаны отдельно выше. Полный аудит стороннего исходного кода Whisper не проводился.

Указание старой документации «не переносить OpenAI» относится к прежнему Mac-проекту и не применяется к новой задаче: пользователь прямо требует поддержку OpenAI. Упомянутый в документации старый Windows-проект не использовался и не исследовался.

## 3. Что нельзя переносить буквально

| Компонент Mac | Решение для Windows |
|---|---|
| AppKit и строка меню | WPF: настройки и оверлей; системный значок в трее через готовую Windows-интеграцию. |
| AVFoundation | WASAPI через NAudio; выбор аудио endpoint, ресемплинг и обработка отключения устройства. |
| Опрос модификаторов | Windows-служба хоткеев внутри пользовательского процесса: низкоуровневый клавиатурный перехват для удержания и отпускания, минимальная работа в обработчике. Отдельно проверить вариант опроса, если нужен только набор модификаторов. |
| Буфер macOS и Cmd+V | Windows-буфер Unicode и синтетическая последовательность Ctrl+V; проверка фокуса, отпускания клавиш и ограничений прав. |
| Apple Translation | Не переносится: перевод исключён пользователем. Вместо него появляется независимый этап коррекции текста через OpenAI, которого в Mac-версии нет. |
| FluidAudio / Core ML / ANE | Не переносится напрямую. Live-функцию можно заменить OpenAI Realtime; локальный Parakeet через другой runtime потребует исследования совместимых весов, лицензий, декодера и производительности. |
| CPU + Apple Accelerate | Windows Whisper с CPU-резервом и GPU-ускорением. Основной кандидат — Vulkan для AMD/NVIDIA; CUDA — дополнительная оптимизация NVIDIA, если измерения оправдают вторую поставку. Поддержка конкретных карт и зависимостей проверяется прототипом. Возможности перечислены в [документации включённого движка](../voice-capture-mac/Vendor/whisper.cpp/README.md:31). |
| SwiftPM, macOS bundle и подпись | Windows-сборка .NET, самодостаточная поставка и, при необходимости, установщик и подпись Windows. |
| Каталог Application Support и файловая блокировка | Локальное хранилище данных пользователя Windows, именованная блокировка экземпляра в пользовательском сеансе. |

Можно сохранить модели Whisper совместимого формата после проверки версии движка. Нельзя использовать готовую Mac-библиотеку на Windows. GPU и наличие локальной модели не требуются для облачного OpenAI-режима.

## 4. Замечания к исходной реализации

Ниже — выводы чтения кода, а не результаты запуска. Они нужны для проектирования новой версии; исправлять Mac-исходники в текущей задаче не предлагается.

1. **Ключ API хранится открыто вместе с настройками.** Маскировка поля в интерфейсе не защищает файл. Для Windows секреты необходимо вынести в системное хранилище. [Сохранение настроек](../voice-capture-mac/Sources/VoiceCapture/Settings.swift:230).
2. **Форматы дат истории не согласованы.** Запись задаёт ISO 8601, чтение использует стандартную стратегию декодера. Непустая сохранённая история с датами не должна корректно восстанавливаться по этому пути; при ошибке создаётся новая история. [Чтение и запись](../voice-capture-mac/Sources/VoiceCapture/RecognitionHistory.swift:69).
3. **Тайм-аут не отменяет вычисление.** Через 90 секунд сбрасывается флаг занятости, но поздний результат может дойти до вставки уже во время другой диктовки. Требуются отмена и идентификатор сессии для всех ветвей. [Watchdog](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:261).
4. **Гонка движков завершается несимметрично.** Если Local не дал результат первым, а Groq отказал позднее, ошибка обоих не обрабатывается сразу в ветке Groq; остаётся ожидание watchdog. Проигравшая работа также не отменяется. [Обработка гонки](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:465).
5. **Неочевидная деградация совместного режима.** Гонка разрешена только при наличии и ключа, и модели. Если ключ есть, а модели нет, выбор совместного режима переходит к Local и ошибке отсутствующей модели, а не к доступному облаку. [Условие гонки](../voice-capture-mac/Sources/VoiceCapture/Settings.swift:243), [выбор распознавателя](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:617).
6. **Вставка не привязана к исходному окну.** Пользователь может переключиться за время распознавания; по истечении ожидания модификаторов вставка выполняется даже с удерживаемыми клавишами. Для Windows необходим безопасный отказ от авто-вставки, а не принудительная отправка. [Ожидание перед вставкой](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:595).
7. **Ресурсы и приватность.** Запись и snapshot-preview не имеют явного лимита длительности; повторный анализ растущей записи увеличивает стоимость вычислений. Полные тексты выводятся в системные логи. В Windows нужны лимит, ограниченная очередь и логи без содержимого диктовок по умолчанию. [Preview](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:333), [вывод результата](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:539).
8. **Перевод требует отдельной защиты.** Конфигурация переводчика при следующем запросе только инвалидируется, но не пересоздаётся при смене целевого языка — риск сохранения старого языка. После распознавания watchdog отменён, отдельный тайм-аут перевода отсутствует. [Конфигурация перевода](../voice-capture-mac/Sources/VoiceCapture/AppleTranslationService.swift:233).
9. **Загрузки и настройки недостаточно защищены от повреждения.** В загрузчике Whisper нет явной проверки HTTP-статуса и контрольной суммы перед заменой старой модели; ошибки записи настроек подавляются. Для Windows нужны проверка скачанного содержимого, временный файл и атомарная замена. [Сохранение модели](../voice-capture-mac/Sources/VoiceCapture/SettingsWindowController.swift:451).
10. **Документация частично устарела.** В старых разделах указан прежний аудиодвижок и перехват хоткеев, тогда как код использует другой захват и опрос; меню показывает 3.3 при сборке 3.4.0. Источником функциональной картины принят код. [Меню](../voice-capture-mac/Sources/VoiceCapture/AppDelegate.swift:125), [версия сборки](../voice-capture-mac/build_app.sh:17).

| **C# + WPF + .NET LTS** | Зрелая Windows-интеграция; удобные трей, окна, буфер, асинхронная сеть; без браузерного runtime. | Только Windows; самодостаточная поставка включает .NET; системные вызовы и аудио требуют аккуратной реализации. | **Выбрано пользователем.** Точную LTS-версию и минимальную сборку Windows 10 закрепить после проверки матрицы поддержки Windows 10/11. |
| C# + WinUI 3 | Современный Windows-интерфейс. | Дополнительные нюансы трея, прозрачных неактивируемых окон и распространения; мало преимуществ для маленькой фоновой утилиты. | Выбирать, если современный системный внешний вид важнее простоты. |
| Python + PySide6 | Быстрый прототип; удобство экспериментов с локальными ML-движками. | Упаковка runtime, нативные зависимости, размер и обслуживание фонового приложения; необходимо проверить лицензирование поставки. | Подходит при приоритете ML-экспериментов или обязательном Python. |

Буквальный перенос Swift не сохраняет Apple-фреймворки на Windows и не даёт значимого выигрыша. Общий новый Mac/Windows-код сейчас не является требованием.

## 6. Предлагаемая архитектура

### 6.1. Пользовательский поток

Хоткей → захват микрофона → проверка сигнала → OpenAI / Whisper / гибрид → коррекция финального текста через OpenAI, если включена → буфер → безопасная авто-вставка. Истории и перевода нет.

Предлагаемый интерфейс: значок в трее; меню «Режим распознавания / Коррекция / Настройки / Приостановить хоткей / Выход»; компактный оверлей с состояниями записи, распознавания, коррекции и ошибки. Если live будет включён в релиз — многострочный предварительный текст в пределах рабочей области монитора, без вставки в приложение до отпускания хоткея. Счётчики Mac не обязательны; предложение — исключить их из первого релиза вместе с историей.

### 6.2. Разделение ответственности

| Модуль | Ответственность |
|---|---|
| Оболочка | Трей, настройки, оверлей, состояния и уведомления; без просмотра истории. Не выполняет распознавание сама. |
| Координатор диктовки | Одна активная сессия, снимок настроек, отмена, тайм-ауты, последовательность стадий, запрет поздних результатов и двойной вставки. |
| Windows-интеграция | Хоткеи, устройства, захват, буфер, окно назначения, вставка, блокировка второго экземпляра, события сна и блокировки сеанса. |
| Аудиоподготовка | Ограниченные буферы, сведение в моно, ресемплинг, уровень сигнала, упаковка аудио под конкретный провайдер. |
| Распознавание | Единый асинхронный контракт: финальный результат, опциональные промежуточные результаты, язык, модель, источник, отмена и типизированные ошибки. |
| Провайдеры | OpenAI, Local Whisper и координация их гонки; единая точка выбора победителя. Groq не входит в релиз. Возможный Realtime — отдельная реализация после решения по live. |
| Коррекция | Один запрос OpenAI после выбора финального результата; консервативная правка, тайм-аут, переключатель и возврат исходника при ошибке. |
| Хранилища | Настройки без секретов, системное хранилище ключа, каталог моделей и техническая диагностика; аудио и тексты не сохраняются приложением на диск. |

Для первой версии достаточно нескольких логических слоёв, без сервера, микросервисов, универсальной плагинной платформы и лишнего процесса. Отдельный локальный ML-процесс рассматривать только при необходимости изоляции падений или принудительной остановки нативного движка.

### 6.3. Состояния и гарантии

Ожидание → запись → распознавание → коррекция, если включена → подготовка вставки → завершение. Из любой активной стадии доступны ошибка или отмена с освобождением ресурсов.

- Каждая сессия имеет собственные настройки, режим коррекции, окно назначения и маркер отмены.
- В первой версии новая диктовка во время обработки не принимается; оверлей объясняет занятость. Очередь диктовок — только по отдельному требованию.
- Esc отменяет активную диктовку или обработку; без активной сессии не перехватывается приложением.
- Отмена, тайм-аут, блокировка сеанса, сон или выход исключают последующую автоматическую вставку. Отмена HTTP-запроса не гарантирует прекращение расчёта или списаний у провайдера.
- При смене микрофона во время записи лучше остановить с объяснением, чем незаметно продолжать другим устройством. Перед новой записью допустим предложенный пользователю возврат к системному.
- Локальный нативный контекст не используется конкурентно. Если движок не остановился физически, поздний результат игнорируется, а новый запрос не использует занятый контекст.

### 6.4. Особенности Windows

**Предлагаемый хоткей: левый Ctrl + левый Alt + Space, удерживать во время речи.** Все три клавиши нажаты — начинается запись; первая из них отпущена — запись заканчивается. Это аналог поведения Mac, но не буквальная замена Cmd на Win: Ctrl+Win может задевать системные комбинации, Ctrl+Shift и Alt+Shift — переключение раскладки. Дополнительного модификатора перевода нет; коррекция управляется настройкой. Esc отменяет активную сессию.

Space в распознанной комбинации подавляется, чтобы не печатать пробелы; обычный пробел и другие сочетания продолжают работать. Нужно проверить, что отпускание Alt не активирует меню и что AltGr не запускает запись. Хоткей переназначаемый; возможные конфликты, например с IDE, проверяются на целевых приложениях, универсально свободная комбинация не обещается. Обычной регистрации хоткея недостаточно для всех сценариев удержания и отпускания. Обработчик не должен выполнять сеть или ML и не должен собирать текст пользовательского ввода.

**Вставка.** Оверлей не активируется и не крадёт фокус. Перед вставкой проверяются исходное активное окно и отпускание клавиш; при изменившемся фокусе результат остаётся для ручной вставки. Совпадение окна не гарантирует неизменность поля внутри него — этот остаточный риск должен быть понятен пользователю. Не возвращать фокус принудительно. Не имитировать Enter после текста.

**Ограничения прав.** Обычный пользовательский процесс не гарантирует ввод в программу, запущенную с повышенными правами. Не предлагать постоянный запуск от администратора как базовое решение. UAC secure desktop и экран входа вне поддержки; для неподдерживаемой цели — ручное копирование. Терминалы, RDP и защищённые поля требуют отдельных проверок.

**Буфер.** Повторять попытки захвата занятого буфера с ограничением времени. Предлагаемый вариант оставляет результат в буфере и не восстанавливает предыдущий буфер. При смене окна или ошибке вставки текст доступен только в буфере, без истории. Приложение не может надёжно подтвердить, что чужое поле приняло Ctrl+V, только факт отправки событий. История и облачная синхронизация буфера самой Windows или сторонний менеджер могут отдельно сохранять текст: отсутствие истории приложения этого не исключает. Для чувствительных диктовок предложить отключить эти функции Windows и проверить возможность пометки содержимого как исключённого из истории/синхронизации.

**Аудио.** Устройство открывается в поддерживаемом им формате, а не с предположением, что любой микрофон выдаёт 16 кГц. Формат для обычной транскрипции — моно WAV PCM16 как простой исходный вариант; локальный Whisper получает 16 кГц. Realtime получает отдельно проверенный требуемый формат. Усиление 60× и Mac-порог тишины не копируются без измерений на Windows.

**Дисплеи.** Проверки нескольких мониторов, изменения DPI, масштабов 100–200%, расположения панели задач и восстановления после отключения экрана.

## 7. Интеграция OpenAI

### 7.1. Распознавание

Предлагается сначала обычная отправка завершённой записи в Audio Transcriptions API. Это воспроизводит основной сценарий и значительно проще настоящей потоковой сессии.

Кандидаты для проверки: **gpt-4o-mini-transcribe** как первый кандидат при приоритете скорости, **gpt-4o-transcribe** для сравнения качества, **whisper-1** как дополнительный совместимый вариант. Это предварительный список, не подтверждение актуальной доступности и не гарантия, что меньшая модель быстрее в сети пользователя. Выбор — по измеренной полной задержке и качеству русского/английского текста. Для смешанной речи предлагается автоопределение без принудительного перевода; его качество проверяется на фразах с переключением языка внутри предложения. Модель можно менять в настройках; параметры учитывают возможности конкретной модели.

Необходимы: ввод и удаление ключа; выбор модели; язык или автоопределение; подсказка терминов; понятные ошибки авторизации, доступа к модели, квоты, ограничения частоты, сети и превышения размера. Проверка ключа не должна ограничиваться только форматом строки или наличием модели в общем списке: доступ к аудио-функции проверяется отдельной согласованной короткой пробой.

До реализации проверяются актуальные максимальные размеры и длительность, форматы ответа и входа, поддержка подсказок и языка, тайм-ауты. Предлагаемый лимит диктовки — пять минут с предупреждением перед остановкой; пользователь длительность пока не уточнил. Длинные записи и автоматическая склейка частей не входят в предложенный первый релиз.

Автоповторы ограничены. Ошибки ключа и прав не повторяются; временные сбои обрабатываются с задержкой и учётом указаний сервера. Не повторять бесконечно неоднозначно завершившийся платный запрос. Аудио удерживается только в рамках активной сессии и короткого явно выбранного повторного запроса, а не сохраняется скрыто на диск.

### 7.2. Коррекция текста вместо перевода

Коррекция обязательна как функция первого релиза. Предлагается отдельный переключатель, включённый по умолчанию для облачного и гибридного режимов. В полностью локальном профиле она выключена; вариант «Whisper + облачная коррекция» включается явно и помечается как требующий сети.

После финального распознавания текст передаётся быстрой текстовой модели OpenAI через Responses API. Корректор вызывается **один раз после выбора победителя**, не для каждого движка и не для промежуточного live-текста. Модель коррекции выбирается отдельно; конкретное имя утверждается после проверки актуальных моделей и задержки на коротких русских/английских диктовках.

Предлагаемая консервативная политика:

- Исправлять пунктуацию, регистр, очевидные опечатки и грамматику, сохраняя смысл и язык каждого фрагмента.
- Не переводить, не пересказывать, не сокращать, не добавлять факты; не удалять повторы и слова-паразиты без отдельного режима.
- Особенно бережно сохранять числа, имена, термины, адреса и продиктованные фрагменты кода. Модель не гарантирует абсолютную точность — нужны проверочные примеры и возможность отключить коррекцию.
- Передавать транскрипт как обрабатываемые данные, а не команду приложению; не подключать инструменты модели. Ответ содержит только исправленный текст.
- Держать исходник лишь в памяти до завершения текущей сессии. При ошибке, пустом/оборванном ответе или превышении отдельного тайм-аута предлагается вставить исходный транскрипт с уведомлением «Без коррекции». При полной отмене сессии не вставлять ничего.
- Для скорости предварительный тайм-аут коррекции — 3 секунды для короткой диктовки, настраивается после измерений. Для длинного текста бюджет уточняется отдельно. Поздняя коррекция никогда не заменяет уже вставленный исходник.

Второй запрос добавляет задержку и стоимость. При оценке скорости измеряется весь путь от отпускания хоткея до финального текста, а не только распознавание. Отсутствие истории не отменяет необходимость временного исходника в памяти для безопасного отказа корректора.

### 7.3. Whisper и гибрид в первом релизе

**Локальный Whisper:** Windows-сборка, совместимая .NET-обёртка либо небольшой нативный адаптер. Сначала проверить соответствие версий, отмену, Unicode-пути, работу из памяти и отсутствие временных аудиофайлов. Модели скачиваются явно из настроек, с прогрессом, проверкой целостности и атомарной заменой. Модель прогревается и переиспользуется.

Для AMD и NVIDIA первым кандидатом является Vulkan; CPU — обязательный резерв при отсутствии совместимого GPU/драйвера или нехватке видеопамяти. CUDA для NVIDIA добавляется только при подтверждённом выигрыше. Нельзя обещать одинаковую скорость на любой карте только по году выпуска.

Кандидат по умолчанию при рабочем GPU — многоязычный Whisper large-v3-turbo; small/base — облегчённые альтернативы для CPU или недостатка памяти. Это гипотеза для измерений, а не гарантия задержки при 16 ГБ RAM. Англоязычные модели не подходят в качестве единственной модели для русского и смешанной речи.

**Три режима распознавания:** OpenAI; локальный Whisper; гибрид OpenAI + Whisper. Гибрид заменяет сочетание Groq + Local из оригинала:

1. После отпускания хоткея облачный запрос запускается сразу.
2. Если ответа нет через настраиваемую задержку, запускается прогретый Whisper. Приоритет скорости: предложенный стартовый профиль — оба сразу при доступном GPU и задержка 0,5 секунды при CPU-резерве. Значения проверяются измерениями, диапазон настройки включает ноль.
3. При ранней ошибке облака локальный запуск немедленный. Первый успешный непустой финальный транскрипт выигрывает; пробельный результат успехом не считается.
4. Проигравшая операция отменяется по возможности, а её поздний результат всегда игнорируется. Коррекция и вставка выполняются только для победителя, по одному разу.
5. При отказе обоих движков ошибка показывается немедленно после завершения обоих, независимо от порядка; общий тайм-аут ограничивает зависания.
6. Если один движок не настроен, до записи явно сообщается о работе только доступного; отсутствие обоих блокирует запуск с инструкцией настройки. В локальном режиме нет скрытого переключения в облако.

Гибрид оптимизирует время выбора транскрипта, но не гарантирует лучшее качество: быстрый результат может быть менее точным. Победа Whisper не отменяет возможную оплату уже принятого OpenAI-запроса. При отсутствии сети локальная диктовка доступна без облачной коррекции; отказ корректора не должен превращать её в неработоспособный режим.

### 7.4. Live исключён из первого релиза

Пользователь выбрал A. Во время удержания хоткея отображается только состояние записи. Нет Realtime-соединения, промежуточных транскриптов и дополнительной нагрузки preview. FluidAudio/Parakeet и другие локальные ML-runtime не включаются.

### 7.5. Ключи, приватность и доступность

- Личный ключ хранится через Windows Credential Manager либо защищается DPAPI в контексте текущего пользователя; в настройках только ссылка на секрет. Это защита хранения, не защита от вредоносного ПО с правами пользователя.
- Ключ не встраивается в распространяемое приложение, не выводится в логи, историю и экспорт. Если потребуется общий ключ владельца продукта, нужен сервер с аутентификацией и лимитами — это другая архитектура.
- История текстов отсутствует. Аудио, промежуточные транскрипты, исходник и исправленный текст обрабатываются в памяти, без файлов приложения и отладочных дампов содержимого. Буферы освобождаются после завершения/отмены; не обещается криптографическое стирание управляемой памяти или отсутствие системного paging/crash dump.
- Логи содержат только технические статусы и длительности. Не писать туда тела запросов/ответов, поскольку в них могут быть тексты, аудио или секреты. Сохраняются только настройки, ключ в системном хранилище и скачанные модели.
- Перед первым облачным использованием показывается передача аудио OpenAI; коррекция отправляет текст даже при локальном Whisper. Полностью офлайн-профиль — Whisper без облачной коррекции и без облачного live.
- В первом релизе только прямой OpenAI API. Azure OpenAI, совместимые шлюзы и общий встроенный ключ исключены. Проверка доступа и отдельного API-биллинга остаётся необходимой.
- Подписка ChatGPT не заменяет настройку API-биллинга. Доступность в регионе и сети, корпоративный прокси и правила обработки данных выясняются до подключения. Обход ограничений не является частью проекта.
- Цены и политика хранения на стороне провайдера здесь не зафиксированы: их нужно проверить перед запуском. Отключение сохранения ответа приложением не означает нулевое хранение со стороны провайдера.

### 7.6. Ограничение внешней проверки

## 9. Проверки и критерии качества

Автоматизация тестов для новой Windows-версии предлагается независимо от исторического решения не писать тесты для Mac. Минимальный набор:

- Состояния диктовки: завершение, отмена, тайм-аут, смена настроек, поздний ответ и два провайдера; ровно одна фиксация результата.
- Хранилища: миграция настроек, повреждённый файл, атомарная запись, ключ только в защищённом хранилище; после диктовки и перезапуска нет файлов с аудио, транскриптами и историей.
- Коррекция: русский/английский/смешанный текст, числа, имена, термины и отрицания; консервативная правка без перевода; один вызов после победы в гибриде, исходник при отказе, отсутствие поздней подмены.
- Аудио: разные частоты и число каналов, отсутствие устройства/буферов, тишина, тихая речь, короткое нажатие, достижение лимита, отключение USB/Bluetooth.
- Сеть: неверный ключ, запрещённая модель, квота, ограничение частоты, тайм-аут, разрыв; отмена не запускает повтор без согласия.
- Windows: RU/EN и AltGr, удерживаемые модификаторы, быстрое повторное нажатие, сон, блокировка, несколько дисплеев и DPI, занятый буфер.
- Вставка: предложенный набор основных приложений — Блокнот, Edge/Chrome, VS Code, Word и Telegram Desktop. Пользователь конкретный список не называл; поддержка терминала, RDP и повышенных прав не обещается и не включается без отдельного требования. При смене окна — только буфер, без принудительного возврата фокуса.
- Приватность: в полностью локальном профиле не отправляются аудио/текст; облачная коррекция обозначена явно; нет истории приложения, текстов/тел запросов в диагностике. Отдельно проверяется взаимодействие с историей буфера Windows.
- Производительность: измерять холодный/прогретый старт, задержку от отпускания до текста, память и CPU на согласованном ПК. Не обещать фиксированную скорость облака без измерений. Предварительная цель реакции локального интерфейса на хоткей — до 150 мс на согласованной машине.
- Лицензии: для Whisper подтверждена [MIT-лицензия](../voice-capture-mac/Vendor/whisper.cpp/LICENSE:1); лицензии Windows-пакетов, выбранных моделей и права на распространение исходного приложения проверяются перед выпуском. Отсутствие лицензии самого приложения нельзя компенсировать лицензией его зависимости.

## 10. Утверждение

21 сентября 2026 года пользователь выбрал **A — без live**, утвердил план и разрешил начать разработку.

### Принятые значения по умолчанию

- Левый Ctrl + левый Alt + Space, удержание; Esc отменяет. Переназначение доступно.
- Коррекция консервативная, отключаемая; при её ошибке вставляется исходник с уведомлением. Для полностью офлайн-работы облачная коррекция выключена.
- Проверяем Блокнот, Edge/Chrome, VS Code, Word и Telegram Desktop как предложенный набор «основных приложений».
- При смене окна не вставляем автоматически; результат остаётся в буфере без восстановления прежнего содержимого.
- Лимит записи пять минут; русский интерфейс; самодостаточный x64-архив для личного использования; автозапуск по желанию, без автообновления и обязательной подписи первого выпуска.
- Не сохраняем историю и суммарные счётчики диктовок. Никаких файлов с голосом/текстом; ключ защищён системным хранилищем.

Точные версии ОС, модель GPU/VRAM и микрофон проверяются при техническом этапе; без этого заявляется целевой класс оборудования, но не подтверждённая GPU-совместимость. Ключ не передаётся в переписке.
