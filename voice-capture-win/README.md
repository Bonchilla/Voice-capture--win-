# VoiceCapture Windows 0.2.0 — sherpa-onnx / NVIDIA Parakeet TDT v3

Голосовая диктовка для Windows 10/11 x64 на C# / WPF / .NET 10. Удерживайте **левый Ctrl + левый Alt + Space**, говорите, отпускайте — приложение распознает речь, при необходимости исправит текст и отправит его в исходное активное окно.

**Статус:** реализация проверена сборкой, 54 автотестами и реальным локальным распознаванием на Windows 10. Живая русская диктовка с вашим микрофоном, OpenAI и вставка в сторонние приложения остаются пользовательской приёмкой. Замена модели не означает доказанного исправления любых проблем микрофона.

## Что изменилось

- Вместо Whisper используется **sherpa-onnx 1.13.8 + NVIDIA Parakeet TDT 0.6B v3**, многоязычный ONNX INT8. Это v3, не англоязычный v2.
- Локальная модель автоматически определяет язык, поддерживает 25 языков, включая русский и английский, пунктуацию и регистр. Поля языка и терминов применяются **только к OpenAI**. Смешанная речь требует отдельной проверки качества.
- Вычисления выполняются на **CPU через ONNX Runtime**. NVIDIA GPU, CUDA и Python не нужны. Intel UHD/AMD/NVIDIA могут быть установлены, но не используются для ускорения в этой поставке. Прежний Vulkan Whisper удалён из зависимостей.
- Захват микрофона остаётся Windows WASAPI/NAudio; sherpa-onnx выполняет распознавание подготовленного аудио. Голос не записывается приложением на диск.
- Четыре компонента модели, **670 478 772 байта, около 640 МиБ**, скачиваются отдельной командой в настройках. Версия экспорта и SHA-256 закреплены в каталоге; все файлы проверяются до активации пакета и при холодной загрузке.
- При открытии старых настроек локальная модель меняется на Parakeet, ускорение — CPU, показывается уведомление. Остальные параметры, облачные разрешения, ключ и хоткей сохраняются. Файл настроек обновляется только после «Сохранить». Старые модели Whisper не удаляются и больше не используются.
- OpenAI, гибрид «первый успешный», однократная коррекция, трей, хоткей и безопасная вставка сохранены.

## Быстрый запуск

1. Завершите старую версию через меню трея. Распакуйте **весь** новый архив в отдельную постоянную папку: не переносите один исполняемый файл.
2. Запустите [VoiceCapture.Windows.exe](artifacts/publish/0.2.0/win-x64/VoiceCapture.Windows.exe). В архиве он находится в корне распакованной папки.
3. Разрешите доступ к микрофону для классических приложений в параметрах конфиденциальности Windows.
4. Выберите правильный микрофон и **«Parakeet TDT v3 — локально»**.
5. В разделе sherpa-onnx нажмите **«Скачать / проверить»**. Дождитесь загрузки около 640 МиБ. При обновлении требуется дополнительное место под временную и предыдущую копии. Программа не скачивает модель скрыто при старте.
6. Для первой проверки отключите облачную коррекцию локального режима: так проверяется именно Parakeet. Выберите Auto или CPU — оба сейчас используют CPU.
7. Нажмите **«Сохранить»**, дождитесь подготовки модели, затем **«Закрыть в трей»**. Первый прогрев занимает несколько секунд; модель далее остаётся в памяти. Пока настройки открыты, хоткей отключён.
8. Поставьте курсор в Блокнот. Сначала удерживайте левый Ctrl и левый Alt, затем Space. После появления индикатора говорите, завершите фразу и отпустите клавиши.
9. **Esc** отменяет запись/ожидание результата. Выход — через значок в трее.

Для облачного режима введите личный OpenAI API-ключ, разрешите передачу аудио/текста и выберите модели. API оплачивается отдельно от ChatGPT. Проверка ключа обращается только к списку моделей и не подтверждает биллинг/доступ к аудиомодели. Ключ не передавайте в переписке.

Для гибрида настройте оба источника. Облако стартует сразу, Parakeet по умолчанию через 500 мс; ноль запускает оба сразу. Ранний отказ облака запускает локальный движок без задержки. Побеждает первый непустой успешный результат, не обязательно самый точный. Уже принятый облачный запрос может тарифицироваться и после победы Parakeet.

## Поведение и ограничения

- Live, перевод, история, запись системного звука и импорт пользовательских аудиофайлов отсутствуют.
- Полностью офлайн: локальный режим с **отключённой облачной коррекцией**, после скачивания модели. Разрешённая локальная коррекция отправляет текст OpenAI.
- Коррекция консервативная и отключаемая. При её ошибке или тайм-ауте остаётся исходник с уведомлением «Без коррекции». При полной отмене ничего не вставляется. Числа, имена и важные формулировки проверяйте самостоятельно.
- Максимум записи — 5 минут. Для ограничения памяти Parakeet длинная запись распознаётся последовательными блоками до 25 секунд, с поиском тихой границы после 20 секунд. Все сэмплы сохраняются между блоками, но слово без паузы на стыке может быть искажено. Это не настоящий streaming/live и не гарантия качества длинных диктовок.
- Esc сразу прекращает ожидание. Выполняющийся синхронный нативный блок физически дорабатывает; его результат отбрасывается. Следующий локальный расчёт ждёт освобождения контекста. Принудительная остановка нативного процесса не реализована.
- Если активное окно изменилось, модификаторы удерживаются или вставка недоступна, результат остаётся в буфере. Приложение не нажимает Enter и не возвращает фокус насильно. Оно не гарантирует вставку в повышенные/защищённые окна, терминалы или RDP и не отслеживает смену поля внутри того же окна.
- Прежний буфер не восстанавливается. В трее доступны настройки, пауза хоткея, отмена и выход.
- Слишком тихий сигнал и записи короче 0,1 с отбрасываются. Автоматического усиления, VAD и шумоподавления нет. Неправильный микрофон или плохой сигнал смена ASR-модели не исправляет.

## Требования

Windows 10/11 x64, RAM от 16 ГБ, микрофон, ориентир CPU класса Intel i5-12400. Испытан текущий Windows 10 22H2 ПК с Intel UHD 630; распознавание работает на CPU. Драйверы и системные настройки не меняются.

- Самодостаточная поставка включает .NET 10, SDK устанавливать не нужно.
- Для нативных библиотек может понадобиться **Microsoft Visual C++ Redistributable x64 2019–2022 или новее** с [официального сайта](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
- Unicode-пути модели передаются нативному API в UTF-8; загрузка из каталога с кириллицей испытана.
- Windows 11 и чистая машина пока требуют ручной проверки. Запуск на Windows 10 не означает продления её официального жизненного цикла Microsoft.
- Сборка не подписана. Не отключайте антивирус или системную защиту.

## Приватность

Аудио и транскрипты живут только в памяти приложения, результат — в буфере и выбранном окне. В LocalAppData → VoiceCapture находятся настройки, защищённый DPAPI-ключ и модели. DPAPI защищает секрет в контексте текущей учётной записи, но не от вредоносной программы с теми же правами. Очистка поля ключа и сохранение удаляют ключ.

Приложение помечает буфер как исключённый из истории/синхронизации Windows, однако сторонние менеджеры могут игнорировать пометки. Отсутствие данных в системном paging или дампах не гарантируется. Для коррекции отключено сохранение Responses-объекта; собственные правила обработки данных OpenAI остаются применимыми. Живой API и действующие условия аккаунта не проверены.

## Проверки 21 сентября 2026

- **54 автотеста:** гибрид, отмена, однократная коррекция/тайм-аут, офлайн-приватность, HTTP-контракты OpenAI на заглушках; миграция настроек; пакет модели, повреждение/усечение/HTTP-отказ/отмена с сохранением старой копии; границы блоков; преобразование аудио и сохранение уровня/частоты/длительности.
- Модель скачана штатным загрузчиком и успешно загружена на Windows 10 из Unicode-пути. Английский публичный фрагмент: холодный проход 8,0 с, прогретые 0,82 / 0,80 / 0,87 с.
- Русский тест через локальный Microsoft Irina (синтетический, не микрофон): короткая фраза — контрольные слова «тестовая», «запись» найдены; расширенная — шесть контрольных слов найдены. Прогретые медианы около 0,75–0,80 с. Числовой формат и пунктуация автоматически не оценивались. Это не измерение WER или гарантия точности живой речи.
- Отмена и повторное использование на английском и русском материале успешны. Ни один тест не обращался к OpenAI или микрофону.
- Холодные времена включают проверку целостности и загрузку модели; результаты не являются обещанием полной задержки диктовки.
